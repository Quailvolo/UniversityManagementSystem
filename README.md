# University Management System

## Description

University Management System is a console application written in Java.

### Features

- Student management
- Teacher management
- Course management
- Enrollment management
- GPA calculation
- Student search
- Bubble Sort
- Reports
- Exception handling

## Technologies

- Java
- OOP
- Arrays
- Scanner
- Enums
- Interfaces

## Project Structure

```
src/
 └── university/
      ├── entities
      ├── enums
      ├── interfaces
      ├── services
      ├── util
      └── Main.java
```
